# Claude Certified Architect – Foundations Bootcamp

This repository contains the materials for a four-day, 16-hour CCAR-F bootcamp.
The course progresses from agent architecture to Claude Code and tool design,
then MCP and structured output, and finishes with context management,
integration, and exam practice.

## Start here

Use [`CCAR-F_Bootcamp_Resources_Aug_2026_Current/`](./CCAR-F_Bootcamp_Resources_Aug_2026_Current/)
as the authoritative source for the current syllabus, instructor bio, daily
slide decks, and lab guides. Follow the days in order:

1. **Day 1 — Agentic Architecture & Orchestration:** agent loops, `stop_reason`,
   multi-agent topologies, and workflow decomposition.
2. **Day 2 — Claude Code Workflows & Tool Design:** project instructions,
   permissions, CI/CD, and tool descriptions.
3. **Day 3 — MCP & Prompt Engineering:** MCP integration, prompting,
   structured output, and validation-retry loops.
4. **Day 4 — Context Management & Integration:** context reliability, capstone,
   and mock exam.

The `Day_1_Files_Aug_2026/`, `Day_2_Files_Aug_2026/`,
`Day_3_Files_Aug_2026/`, and `Day_4_All_files_Aug_2026/` folders contain
supplementary activities, interactive practice pages, and the Day 3 runnable
MCP example. Any copies of the core decks or lab guides in those folders are
convenience copies; use the consolidated `Current` folder as the source of
truth if copies ever differ.

## Assessment at a glance

The syllabus distinguishes two practice exams:

- **Bootcamp mock exam:** 30 scenario-based questions, a half-length practice
  set, completed during Day 4. The Day 4 lab guide includes the questions,
  answer key, score worksheet, and study-plan template.
- **Take-home practice exam:** a separate full-length 60-question practice
  exam to complete before scheduling the certification exam.

The syllabus describes the certification exam as 60 scenario-based questions
in 120 minutes, with a scaled passing score of 720/1000. Check the current
official exam guide before each cohort because the syllabus notes that exam
blueprints and domain weights may change.
