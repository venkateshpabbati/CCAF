◆ Program overview

15 Hands-On MCP + Claude AI Labs

A practical lab structure for a mixed corporate audience — Development, UI/UX, Business Analysis, QA, Infrastructure, Operations, HR, Sales and Management — built on Claude Code, the Claude API, and MCP servers.

What participants learn, progressively

  • Connect — attach an MCP server to Claude Code or the API
  • Authenticate — securely provide credentials via environment variables
  • Discover tools — explore what an MCP server exposes
  • Prompt — instruct Claude to use those tools toward a business outcome
  • Execute — run real, scoped actions against live systems
  • Validate — check outputs before they're trusted
  • Govern — require human approval before destructive actions
  • Build — author a custom MCP server from scratch

How the labs are organized

Labs 1–3 build MCP fundamentals (GitHub, Figma, and writing your own server). Labs 4–12 apply Claude across specific business functions. Labs 13–15 combine multiple MCP servers into automated, governed, end-to-end workflows.

Note

Store all API keys and tokens as environment variables — never inline in prompts or source code.

Store credentials as environment variables

macOS / Linux

export ANTHROPIC_API_KEY="your-api-key"
export GITHUB_TOKEN="your-github-token"

Windows PowerShell

$env:ANTHROPIC_API_KEY="your-api-key"
$env:GITHUB_TOKEN="your-github-token"
